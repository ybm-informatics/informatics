# 이번 주 진행 사항 및 다음 주 계획

작성일: 2026-07-16

## 이번 주 진행 사항

- 교수학습자료 자동화 프로젝트의 시범 범위를 `중학교 정보 3단원`으로 정했다.
- 우선 자동화할 자료 유형을 교수학습과정안, 수업용 PPT, 학생용 활동지로 정했다.
- 최종 출력 형식은 DOCX, PPTX, PDF, HTML 웹 화면, JSON을 우선 대상으로 정했다.
- NCIC에서 2022 개정 교육과정 별책 10의 중학교 정보 교육과정을 수집하는 도구를 구현했다.
- 중학교 정보 교육과정의 내용 체계 5개 영역과 성취기준 25개를 구조화 JSON으로 추출했다.
- 내용 체계표의 `가치ㆍ태도` 항목 누락과 PDF 글자 간격 문제를 보완했다.
- 교육과정 기준본을 승인하여 `data/ncic/approved/current.json`으로 확정했다.
- 중학교 정보 3단원 교과서 본문과 목차 파일을 업로드하고 보관 폴더를 정리했다.
- 3단원 목차를 기준으로 단원 구조 JSON 초안을 생성했다.

## 다음 주 계획

- 3단원 교과서 본문 PDF를 분석하여 소단원별 핵심 개념, 활동, 실습, 평가 요소를 추출한다.
- 3단원 구조 JSON의 쪽 범위, 차시 구성, 학습목표를 본문 기준으로 보완한다.
- 성취기준 `9정03-01`~`9정03-09`와 각 소단원ㆍ활동의 연결을 검토한다.
- 교수학습과정안 견본 1개를 수집하여 문서 포맷 규칙을 정의한다.
- 교수학습과정안 1차시 자동 생성 초안을 먼저 만든다.
- 이후 같은 구조를 바탕으로 PPT와 학생 활동지 생성 규칙을 확장한다.

## 강사님께 지원이 필요한 사항

- 교과서 3단원의 권장 차시 수와 학교 현장에서 일반적으로 사용하는 차시 배분 기준을 확인해 주시면 좋겠다.
- 교수학습과정안 견본 1개를 제공해 주시면 자동 생성 포맷을 더 정확히 설계할 수 있다.
- 수업용 PPT와 학생 활동지의 필수 구성 요소를 정리해 주시면 자료 유형별 템플릿을 안정적으로 만들 수 있다.
- 자동 생성 결과를 검토할 때 반드시 지켜야 할 편집 기준이나 금지 표현이 있다면 공유가 필요하다.
- 향후 상용 웹 패키지로 활용할 경우, NCIC 교육과정 원문과 교과서 본문 사용 범위에 대한 권리 검토가 필요하다.
