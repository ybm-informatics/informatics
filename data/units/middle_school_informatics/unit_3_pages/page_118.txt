프로그래밍 비밀번호 잠금 장치
따라 하는따라 하는
변수를 만들 때 
설정하고 싶은 
비밀번호를 
미리 지정하자.
공동 현관에서 4자리 비밀번호를 누르면 문이 열리는 잠금 장치는 건물
의 출입자를 관리하는 데 많이 활용된다. 숫자 버튼을 누르면 LED 화면
에 누른 버튼의 수를 출력하려 하는데, 각 숫자 버튼 10개는 모두 같은 
기능을 수행한다. 효율적으로 프로그램을 작성하기 위해서는 어떻게 해
야 할까?
문제 상황
공동 현관에서 4자리 비밀번호를 
누르면 문이 열리는 잠금 장치 
프로그램을 만들고자 한다.
초기 상태
각 숫자 버튼을 눌렀을 때 화면
에 해당하는 번호가 출력될 수 
있는 함수를 정의하여 활용한다.
현재 상태
각 버튼을 눌러 4자리의 숫자를 
화면에 입력하면 저장된 비밀번
호와 비교하여 문이 열리거나 닫
히는 프로그램을 완성하였다.

알고리즘 설계
● 실행 화면에 적절한 오브젝트를 배치하고, 각 숫자 버튼을 눌렀을 때 화면에 해당하는 번호가 출력
될 수 있도록 알고리즘을 설계해 보자.
오브젝트 ‘확인 버튼’을 클릭했을 때
❶ 함수 ‘번호 확인’을 호출한다.
오브젝트 ‘취소 버튼’을 클릭했을 때
❶ 변수 ‘화면’에 공백 문자(‘ ’)를 저장한다.
오브젝트 ‘숫자 버튼’을 클릭했을 때
❶ 함수 ‘숫자 (오브젝트의 숫자) 추가’를 호출한다.
오브젝트 ‘자물쇠’를 클릭했을 때
❶ 오브젝트를 클릭하면 모양을 ‘닫힘’으로 바꾼다.
함수 ‘숫자 [문자/숫자값 1] 추가’
❶ 변수 ‘화면’의 글자 수가 4 미만이면 변수 ‘화면’과 
[문자/숫자값 1]을 합쳐 변수 ‘화면’에 저장한다.
함수 ‘번호 확인’
❶ 변수 ‘입력 비밀번호’에 변수 ‘화면’의 값을 저장한다.
❷ 변수 ‘입력 비밀번호’의 값과 ‘실제 비밀번호’의 값
이 같으면 변수 ‘화면’에 “열렸습니다.”, 그렇지 않
으면 “틀렸습니다.”를 저장한다.
❸ 2초를 기다린다.
❹ 변수 ‘화면‘의 값을 공백 문자(‘ ’)로 정한다.
프로그램을 시작했을 때
[자물쇠]
❶ 변수 ‘입력 비밀번호’의 값과 변수 ‘실제 비밀번호’의 
값이 같으면 오브젝트의 모양을 ‘자물쇠_열림’ 모양
으로 바꾸고, 변수 ‘입력 비밀번호’에 공백 문자(‘ ’)
를 저장한다. 
❷ ❶을 계속 반복한다.
